# Маршруты LifeHub

Каждый экран — отдельный маршрут и отдельная папка. Ниже полный список.

| Маршрут | Назначение |
| --- | --- |
| `/` | Оглавление эталонов: что сделано, схема взаимодействий, ссылки на все экраны. |
| `/kit` | Набор примитивов: цвета, типографика, кнопки, поля, чипы, таблица, состояния. |
| `/today` | Экран дня: план от ИИ, просрочено, сегодня, входящие. |
| `/inbox` | Задачи без проекта, перенос по одной и массово. |
| `/my` | Всё, где я исполнитель или наблюдатель; группировки, фильтры, две плотности. |
| `/projects` | Список проектов: плотная таблица и крупные строки, фильтры, вход в архив. |
| `/projects/$id` | Обзор проекта: сводка от ИИ, ход по статусам, сроки, риск срыва, время. |
| `/projects/$id/tasks` | Таблица задач с деревом подзадач, массовыми действиями и панелью «взглянуть». |
| `/projects/$id/board` | Канбан по статусам с перетаскиванием и сворачиванием колонок. |
| `/projects/$id/files` | Файлы проекта: привязка к задаче, статус извлечения текста, загрузка перетаскиванием. |
| `/projects/$id/notes` | Заметки проекта: решения и договорённости рядом с задачами. |
| `/projects/$id/time` | Отчёт времени за период: суммы по задачам и по людям, оплачиваемое отдельно. |
| `/projects/$id/settings` | Свойства проекта, участники, теги, архивирование, удаление через меню «…». |
| `/tasks/$id` | Рабочее место задачи: содержание, единая лента, свойства, приёмка. |
| `/notes` | Заметки пространства со связями и тегами. |
| `/notes/$id` | Редактор заметки без панели инструментов, автосохранение с временем. |
| `/files` | Файлы всего пространства и статус извлечения текста. |
| `/search` | Поиск по задачам, проектам, заметкам и файлам с подсветкой совпадений. |
| `/time` | Учёт времени: записи за период, ручное добавление, суммы по дням. |
| `/review` | Недельный обзор: что сделано, что стоит, куда ушло время. |
| `/notifications` | Центр уведомлений: упоминания, назначения, приёмка, комментарии. |
| `/settings/space` | Настройки пространства: общие, участники и роли, теги, модули, вид наблюдателя. |
| `/settings/profile` | Профиль, оформление, пароль и каналы уведомлений. |
| `/admin/modules` | Модули системы на всю установку: состояние и включение. |
| `/states/empty` | Все пустые состояния продукта на одной странице. |
| `/states/errors` | 403, 404, 500, потеря сети и работа офлайн. |
| `/states/mobile` | Мобильная сборка ключевых экранов в рамке 390 px. |
| `/auth/login` | Вход, включая ошибку пары почта-пароль. |
| `/auth/register` | Регистрация: личное пространство создаётся сразу. |
| `/auth/reset` | Восстановление пароля и состояние «письмо отправлено». |
| `/auth/invite` | Приглашение по ссылке: кто, куда, с какой ролью; истёкшая ссылка. |
| `/welcome` | Онбординг пустого аккаунта: три шага, каждый можно пропустить. |
